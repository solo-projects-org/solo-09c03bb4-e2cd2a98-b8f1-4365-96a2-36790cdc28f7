# 鲜菜价格指数

Flask + SQLite 的鲜菜报价与环比指数网页工具。上传单月报价 CSV，自动维护
「可比报价对数 → 环比系数 → 定基指数」并可查看断链/恢复情况。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在 compose 命名卷 `price-data` 的 `/data/prices.db`，容器重建不丢。

本地直接运行（Python 3.11+）：

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DATABASE_PATH=./data/prices.db .venv/bin/python run.py
```

## CSV 格式

```csv
月份,摊位,品种,每公斤报价
2025-01,A-01,土豆,3.20
2025-01,A-02,西红柿,6.50
```

- 一次只接受一个月的文件；同月同摊同品种只允许一条，价格必须为正数。
- 支持 UTF-8/GBK 编码、中英文表头别名（month/stall/item/price）。
- 重复上传同一月份 = 整体替换该月报价。
- 首次上传的月份自动成为基月（指数 100），早于基月的报价拒收。

## 规则

| 展示列 | 含义 |
| --- | --- |
| 可比报价对数 | 本月与上月同摊同品种配对成功的组数 |
| 环比系数 | 各组（本月价 / 上月价）的等权平均 |
| 价格指数 | 基月 100，逐月乘以前月指数 × 当月环比系数 |

缺月、或相邻月没有可比报价对时，该月环比为空，指数自该月起留空（断链）；
补报/更正后从断点恢复。页面从基月连续列到最新报价月。

**全精度与下溢保护**：环比系数与指数在计算、缓存阶段一律保留全精度，
只在网页和 CSV 输出时按原位数舍入（环比 4 位、指数 2 位）。连乘在对数空间
进行（`index_log = Σ ln(环比系数)`），即使长链中间的指数小于浮点数能表示的
最小正数（页面显示 0.00），对数链仍然有效，后续连月回升时能还原正确指数，
不会永久卡在 0.00。

**增量重算**：补报/更正某月只重算该月及下一月的环比系数（其余沿用已算结果），
指数从基月重新串联。

**查询一致性**：指数结果单独存放在 `index_months` 表，读指数只读该表，
不读报价明细；读取包在单个读事务里，保证对数、环比、指数来自同一次提交。
每次写入/重建都递增「缓存代际」，读侧拿到的永远是一套完整缓存。

**写入原子性**：一次上传的「写批次 → 替换整月报价 → 重算 → 写指数」在同一事务内，
任一步失败整体回滚，原报价与原指数都保留。

## 旧库与缓存重建

应用启动时自动检测旧结构缓存（无对数链列 / 无缓存版本号）并从**现行报价**
全量重建环比与指数缓存，沿用原有 SQLite 库，不迁移报价数据。重建在单个
`BEGIN IMMEDIATE` 事务内完成：先清旧缓存再全量重算，任一步失败整体回滚，
旧缓存原样保留、仍可读取，且可随时重试。触发方式：

- 启动时自动执行（失败只记日志，不影响读旧缓存）；
- 网页「重建缓存」按钮，或旧缓存提示横幅里的「立即重建缓存」；
- 命令行：`DATABASE_PATH=/data/prices.db python3 rebuild_cache.py`
  （退出码 0 成功、1 失败可重试、2 无报价跳过）。

换报与重建交错时，事务串行化保证已提交的换报一定反映在生效结果中。
应用启动后才挂载/替换进来的旧库也能在手动重建时自动补列，无需重启。

## 样例文件

`samples/` 下是按示例数据生成的 CSV，可直接在网页上传，手工复现同样的流程：

- `2025-01.csv`、`2025-02.csv`、`2025-03.csv`、`2025-05.csv`：正常数据（不传 04 即为缺月）
- `2025-04.csv`：补报用
- `2025-03-alt-stalls.csv`：换成完全不同摊位的报价，用于制造「无可比报价对」

## 演示

首页「演示」区可一键复现：

1. **载入示例数据** — 载入 2025-01/02/03/05，故意缺 04。
2. **补报 2025-04** — 4、5 月指数接续。
3. **换掉 2025-03** — 用完全不同摊位的报价替换，3 月起无可比报价对，指数清空。
4. **恢复 2025-03** — 指数重新接上。
5. **连跌演示（指数归零）** — 月环比 0.01 连跌 5 个月，指数跌破两位小数显示 0.00。
6. **连月回升（指数恢复 100）** — 月环比 100 连涨 5 个月，指数从 0.00 正确恢复到
   100.00，验证下溢后对数链仍能算出正确指数。
